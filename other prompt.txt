--Planning

Two factors

First, to interact with the Xbox USB protocol, we need a controller adapters.
Second, you will need to decide on the control set-up you want. 
Specifically:
If you want to use existing hardware, creating a "Adapted Set-Up"
If you want to create your own hardware, creating a "DIY Set-Up"
Combining these set-ups is also an option but it will be heavily dependant on the adapter you choose.

--DIY Set-Up
--- How this works

You have three paths.

1. We will call this the GPIO Path
-Using the GPIO pins on the adapter itself to have the adapter itself act at the controller.
--An advantage of this is that you have far more direct control and no parsing is necessary
--A disadvantage of this is that you are limited to the GPIO pins unless you buy extenders

2. We will call this the Adapted-HID Path
-This is essentially the same as an adapted controller but with your own 
-One or more Custom HID Joysticks connected to Host Cable of the adapter (HUB needed for 2+ devices)
--An advantage of this is that since you are responsible for the HID Protocol, it is far easier to parse it on the adapter side
--A disadvantage of this is that you need to buy more microcontroller boards

3. We will call this the SBC HUB Path
-Two or more Emulated Steel Battalion Devices connected to HUB connected to the Host Cable of the adapter
--You may think this seems redundant, and you are partially right.
--The advantage here is that we are using the adapter purely as a HUB for Steel Battalion inputs, so we do not need to do parsing, we are merely transferring inputs.
--Another advantage is that you have MANY more options for inputs
--The disadvantage is that you basically can only use this for Steel Battalion unless you reprogram the boards
